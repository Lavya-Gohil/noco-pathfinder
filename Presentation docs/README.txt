NOCO Asset IQ: demo backup

Use this if the Wi-Fi or the live site fails during the presentation.

Live site:    https://lavya-gohil.github.io/noco-pathfinder/
Straight to results: https://lavya-gohil.github.io/noco-pathfinder/#/demo

1. If you can run commands, serve the full app locally:

     cd site
     npx serve .        (needs Node, and internet the first time)
     python -m http.server 8080        (or this, if Python is installed)

   Then open the address it prints, followed by #/demo
   Opening site\index.html by double-click will NOT work.

2. If nothing runs, present from the static files here:

     report-sample.pdf     the executive report
     screenshots\          the key screens in order

Set the theme to Light (sun icon, top right) before presenting. It reads better
on a projector.

The presentation deck is NOCO-Asset-IQ.pptx in this folder. Its speaker notes hold the
timed four-minute script, and hidden slide 11 is the fallback if the internet fails.
